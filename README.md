# Shreya Singh — GitHub Pages Portfolio

A responsive personal portfolio website with a dark tech theme, profile-photo slot, Hacker’s Unity banner section, About Me, skills, achievements, project cards, social links, and an animated 3D cube.

## 1. Upload to GitHub

1. Create a new public repository named `shreyasinghishu2005-hub.github.io` (or any repository name you prefer).
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site. Your URL will be shown in Settings → Pages.

## 2. Add your own photo and banner

- Put your own profile photo in `assets/profile.jpg`.
- If you want to add a real Hacker’s Unity banner image, put it in `assets/hackers-unity-banner.jpg` and add an `<img>` element inside `.banner-strip` in `index.html`.
- Use your own image or an image you have permission to use.

## Notes

- This is a **website**, so it supports CSS styling and an animated 3D cube.
- A GitHub profile `README.md` does **not** run custom CSS or JavaScript. For this design, publish the website with **GitHub Pages**.
- The 3D cube uses Three.js from a CDN, so an internet connection is needed for the full 3D effect.
